# Ai홍수예보 5대 대권역 통합 상하류 네트워크 시각화 대시보드

## 1. 개요 (Overview)
본 대시보드는 5대 주요 권역(낙동강, 낙동강동해, 태화강, 형산강, 회야수영강)의 복잡한 유역망 관계를 직관적으로 분석하고 시각화할 목적으로 개발된 **Streamlit** 기반의 로컬 웹 애플리케이션입니다.

관심 있는 특보지점이나 하류 유역출구 지점을 지정하면, 상류에 연결된 모든 영향 유역들을 알고리즘이 추적하여 지도 상에 붉은색과 오렌지 계열로 강렬하게 **공간 하이라이팅**합니다. 또한 유입의 근원지부터 목표 지점까지 물줄기가 모이는 계통 구조를 마우스 제어가 가능한 **인터랙티브 흐름도(PyVis)**로 렌더링하여 제공합니다.

## 2. 주요 기능 (Key Features)
*   **권역 통합 대형 지도 구현**: 5개 권역 체계의 공간 데이터(GeoJSON)들을 단일 지도 위에 병합하고, 각각 고유의 베이스 색상을 입혀 직관적인 권역 구분이 가능합니다.
*   **실시간 위상(Topology) 추적 엔진**: `.inf` 라우팅 구조 파일들을 읽어들여 해시맵(Hash map)을 구축해두며, 지점 탐색 즉시 단 0.01초 내외로 모든 상류 트리를 스캔해냅니다.
*   **상호작용형 Flowchart**: 정적인 그림파일을 탈피하고, 마우스 휠 스크롤 줌인/줌아웃, 배경 패닝, 개별 노드 상자 드래그 재배치가 전부 허용되는 능동적 네트워크 다이아그램 시스템을 갖추었습니다.
*   **상호 배타적 고속 검색 UI**: 사이드바에서 지점을 탐색 시 Dropdown 메뉴나 직접 통합 검색(텍스트) 등 3원화된 검색 기법을 적용했으며, 한쪽에서 지점이 활성화되면 다른 포커스 박스는 자동으로 초기화되는 UX 릴레이 매커니즘이 반영되어 있습니다.

## 3. 실행 방법 (How to Run)
본 프로그램은 프레임워크 자체의 로컬 웹서버 위에서 구동되므로, 순수 `python` 명령어로는 동작하지 않습니다. 터미널(PowerShell) 환경에서 반드시 **`streamlit run`** 명령어를 사용하십시오.

### 사전 준비 (최초 1회 라이브러리 설치)
```bash
pip install streamlit geopandas folium streamlit-folium pandas pyvis
```

### 🚀 대시보드 서버 띄우기
현재 작업중인 해당 폴더 경로(`D:\RESEARCH\Nakdong`)에 진입한 상태에서 아래 명령어를 실행합니다.
```bash
streamlit run .\interactive_map.py
```
명령어를 타건하는 즉시 방화벽 승인(최초 시)과 함께 기본 인터넷 브라우저 창이 활성화되며 `http://localhost:8501` 주소에서 대시보드가 가동됩니다.

## 4. 필요 데이터 요구사항
이 스크립트는 폴더 트리 안에 다음과 같은 양식의 분석용 소스 파일들이 배치되어 있음을 상정하고 동작합니다:
*   **라우팅 모식 정보**: `30_subbasin_{권역명}.inf`
*   **소유역 공간 파일**: `*유역도_{권역명}.geojson`
*   **검색용 마커 위치 정보**: `*_{권역명}_특보지점.geojson` 및 `*_{권역명}_유역출구.geojson`
*   **하천망 폴리곤 라인**: `낙동강_국가하천.geojson`, `낙동강_지방하천.geojson`

## 5. 유의 사항
모든 방대한 공간 좌표계 데이터들(MB 단위)을 최초 기동 시점에 전부 로딩하고 경량화(Simplification)하며 EPSG:4326으로 형식을 맞추는 작업이 선행됩니다. 이로 인하여 최초 실행 시 약 **5초~10초** 가량의 로딩 딜레이 스피너가 구동될 수 있습니다. 
단 최초 1회 연산 종료 이후에는 메모리 캐시(`@st.cache_data`)가 발동하므로, 설정 변경 시 일체의 지연 없이 매끄러운 반응성을 체험하실 수 있습니다.
